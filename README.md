# Cafe Morrow 学園祭カフェ販売システム

学園祭などの小規模なカフェ運営を想定した、ブラウザーで動作する販売・注文管理デモです。商品選択から会計、注文履歴、在庫・売上の確認までをひとつの画面で操作できます。

## 主な機能

- 商品画像・価格・在庫数を表示するメニュー
- 商品名やカテゴリーでの検索、ドリンク・フード・デザートの絞り込み
- 注文への商品の追加、数量変更、削除、割引の適用
- 10%割引と10%消費税を含む合計金額の計算
- 現金会計時のお釣り計算。クレジットカード・電子マネー・ポイントカードのデモ会計
- 注文確定後の在庫更新と、注文履歴の表示
- 日本語・英語の切り替え
- 管理者画面での商品・在庫の追加、編集、削除と営業状態の切り替え
- 期間別の売上、販売数量、カテゴリー別販売数、売れ筋商品、支払方法別売上、在庫少数商品の表示
- PC・タブレット・スマートフォン向けのレスポンシブ表示

## 管理者ログイン

| 項目 | デモ用の値 |
|---|---|
| ユーザー名 | `admin` |
| パスワード | `admin123` |

ログイン後、商品管理、営業状態の切り替え、売上分析を利用できます。商品管理では商品名、カテゴリー、価格、在庫数を登録・変更できます。

## 画面の使い方

1. 商品一覧でカテゴリーや検索を使って商品を探し、商品カードを押して注文に追加します。
2. 右側の注文欄または「注文内容」で数量を変更し、必要に応じて10%割引を適用します。
3. 「会計」へ進み、支払方法を選びます。現金の場合は預かり金額を入力してから注文を確定します。
4. 注文確定後、履歴に注文が記録され、購入数に応じて在庫が減ります。

営業を終了すると新しい注文を受け付けなくなります。管理者画面から営業を再開できます。

## データと制限事項

- 商品、注文中の商品、注文履歴、営業状態、表示言語などは、ブラウザーの `localStorage` に保存されます。サーバーや別の端末とは同期されません。
- 保存データはブラウザーおよびアクセス元ごとに異なります。ブラウザーのサイトデータを削除すると、保存済みの情報も消去されます。
- 支払方法のうち、現金以外は画面操作を確認するためのデモです。決済サービスや実際のポイント残高には接続されません。
- 管理者ログイン情報はフロントエンドのソースコード内にあるデモ用の固定値であり、認証・認可の仕組みではありません。実店舗や機密データを扱う用途では使用しないでください。
- データはこのブラウザー内に保存されるため、バックアップ、複数端末間の共有、同時利用時の整合性は保証されません。

## ファイル構成
.
├── index.html       画面と画面要素
├── script.js        商品、注文、会計、履歴、管理機能
├── style.css        レイアウトとデザイン
└── images/          ロゴと商品画像

商品画像は `images/` に置き、`script.js` の `productImages` に商品名と画像パスを登録します。画像は商品一覧と注文欄で使用されます。
